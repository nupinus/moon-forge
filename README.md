# 문 포지 (Moon Forge)

Project Moon의 세계관을 차용한 비공식 팬게임입니다. 등장인물·장비는 창작입니다.

뒷골목의 작은 공방에서 장비를 벼리고, 해결사 사무소의 해결사들에게 쥐여 주세요.
해결사들이 현장에서 모아 온 재료로 더 좋은 장비를 만들어 공방과 사무소의 이름을 도시에 떨치는 게임입니다.

- 플레이: 브라우저에서 `index.html`을 열면 됩니다 (설치 필요 없음).
- 저장: 브라우저에 자동 저장됩니다. 다른 기기로 옮길 땐 메뉴의 세이브 코드를 쓰세요.
